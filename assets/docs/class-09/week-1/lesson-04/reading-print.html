Reading · Mouse, keyboard, typing and shortcuts

Computer Literacy & Workplace Digital Skills

Learning goals. Use mouse actions and keyboard keys accurately; type with comfortable posture; apply common Windows shortcuts safely.

1. Mouse actions

A mouse moves an on-screen pointer. Keep it on a flat surface and move gently. Rest your hand loosely.

ActionWhat it does
PointMove the pointer over an item.
ClickPress and release the left button once to select.
Double-clickClick twice quickly, usually to open a desktop item.
Right-clickShow a context menu of actions for the selected item.
Drag and dropHold, move, then release to move an item; check the destination first.
ScrollMove through a page or list using the wheel.

On many laptop touchpads, one finger moves the pointer, tapping clicks, two fingers scroll, and a two-finger tap right-clicks. Gestures vary by device.

2. Pointer clues

Arrow: ready to select. Hand: link. I-beam: text entry. Spinning circle: computer is busy, so wait briefly instead of clicking repeatedly. Two-headed arrow: resize a window.

3. Keyboard essentials

  • Letters and numbers enter text and figures. Spacebar inserts a space; Enter starts a new line or confirms an action.
  • Backspace removes the character before the cursor. Delete removes the character after it or a selection. Check before deleting.
  • Shift makes one capital or upper symbol. Caps Lock toggles uppercase.
  • Arrow keys move the cursor or selection. Home and End move to a line's start or end. Tab moves between fields; Esc cancels or closes some menus.
  • Ctrl and Alt modify another key in shortcuts. Hold the modifier, tap the second key, then release.

4. Comfortable, accurate typing

Typing is not a race. Accurate words and figures save time later, especially in names, dates and financial records.

HabitWhat to do
PostureSupport your feet, relax your shoulders and keep elbows near your sides.
HandsPlace the keyboard in front of you; keep wrists straight and use a light touch.
ScreenPosition it so text is easy to read without leaning toward it.
PacingBegin at a speed that lets you stay accurate; proofread one line at a time.
BreaksLook away regularly and change position during longer tasks.
If discomfort continues: Pause, adjust your position or equipment, and tell your instructor.

5. Useful shortcuts

ShortcutAction
Ctrl + CCopy selected text or item
Ctrl + XCut selected text or item
Ctrl + VPaste copied or cut content
Ctrl + ZUndo the last action
Ctrl + ASelect all in the active field or document
Ctrl + SSave the current file
Ctrl + POpen print options in many apps
Alt + TabSwitch between open windows
Windows + LLock the computer
Windows + DShow or return to the desktop

Copy leaves the original in place; cut is intended to move it when pasted. Shortcuts can vary by app. Save before major changes and confirm the result.

Guided skill check

Try this sequence: Select a file without opening it; open a desktop shortcut; right-click an item and read the options; scroll a document; type a short practice note; correct one error; save it with Ctrl + S. Ask before dragging a real work file.

6. Check your understanding

  1. Which action usually opens a desktop icon?
  2. Which key removes the character before the cursor?
  3. What is the difference between Ctrl + C and Ctrl + X?
  4. Which shortcut saves a current file?
  5. Why should accuracy come before typing speed?
