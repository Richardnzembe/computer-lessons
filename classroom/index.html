Before you upload

How to add these files to Google Classroom

  1. 1 In Classroom, open the class and choose Classwork → Create → Assignment. Use Material for reading and reference files that do not need a score.
  2. 2 Title it with the week and lesson, for example Week 1 · Lesson 2 — Reading, and add the topic Week 1 · Lesson 2 so the classwork stays organised.
  3. 3 Click Add → File and upload the PDF from this page. Students can read the PDF inside Classroom without downloading it.
  4. 4 For the quiz, attach W1L2-Quiz-Interactive.html (or the Lesson 3 file) as a file. Students download it and open it in a browser — it runs offline and marks itself. If you prefer no downloads, post the online quiz link instead (below).
  5. 5 Set the points (quiz 10, assignment 30), a due date and a topic. Post the student files; keep the answer key and teacher guide in Class materials or your drive, not in a student assignment.

What previews and what downloads

Google Classroom displays PDFs inline, so readings, assignments, worksheets, papers and keys all open in the reader. HTML files cannot be previewed by Classroom: students download the file and open it in Chrome, Edge, Firefox or Safari. Everything in the quiz is self-contained — no internet required.
