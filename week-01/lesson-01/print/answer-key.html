5Reading check — suggested answers

1What is a computer? An electronic machine that takes in data, works on it using instructions, produces a result and can store that result. It is defined by these jobs, not by having a screen or sitting on a desk.
2The four jobs, with examples. Input (typing a name), processing (adding a column of numbers), output (a monitor showing the total) and storage (saving the file to a folder).
3Is a smartphone a computer? Yes. It has a processor, memory and storage, takes input through its touchscreen and microphone, produces output on its screen and speakers, and runs programs. Calls are only one of its jobs.
4Which computer for a clinic sharing records with six staff computers? A server. It provides central storage and services to many computers on a network, so staff see the same records and the clinic can manage backups and security in one place.
5Why is storage important? Processing and output are temporary: when the power goes off, unsaved work is lost. Storage keeps files and data for later, so work can be reopened, shared and backed up.
