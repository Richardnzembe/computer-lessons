1Quiz — ten questions

QAnswerCorrect option and explanation
1BThe physical parts of a computer that you can touch. Programs, files and the internet connection are not physical equipment.
2CWindows 11. An operating system is software. A monitor, cable and printer are hardware.
3BCarry out instructions and calculations. The CPU is the brain of the computer; storage, display and power are other parts.
4BRAM is temporary working memory; storage keeps files when the power is off. This is the most important distinction in the lesson.
5CIn storage such as an SSD or hard drive. Only storage keeps a file after shutdown; RAM is cleared and a monitor stores nothing.

7AHDMI. HDMI carries video and sound to a monitor. USB-A is mainly for peripherals, audio for sound, Ethernet for wired networks.

9CMicrosoft Excel. Excel helps the user do a task. Windows, drivers and the BIOS are system software.

5Reading check — suggested answers

1Hardware and software, with examples. Hardware is the physical equipment you can touch, such as a monitor or keyboard. Software is the set of instructions that tells the hardware what to do, such as Windows 11 or Microsoft Word. Neither is useful without the other.
2Why a saved document survives a power cut. The open document sits in RAM, which is temporary and cleared when the power goes off. Saving writes the file to storage — an SSD, hard drive or cloud drive — which keeps it until it is deleted.
3Three jobs of an operating system. Any three of: starting the computer; managing hardware through drivers; managing memory and processing; organising files and storage; providing the desktop and windows; managing users, permissions and security.
4Ports for a monitor and a wired network. A monitor usually uses HDMI or DisplayPort; a wired network uses Ethernet (RJ-45). USB-C may carry video on some computers, but the port must support it.
5When more RAM helps — and when it does not. More RAM helps when many programs, browser tabs or large files are open and the computer is constantly swapping data to storage. It will not fix a slow internet connection, a full or failing drive, malware, overheating or an old processor. Diagnose the cause first.
