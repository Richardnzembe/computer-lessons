The big idea

Hardware needs software — and software needs hardware

Hardware is every physical part you can touch: the case, screen, keyboard, processor, memory, storage and cables.

Software is the set of instructions that tells the hardware what to do. It has no physical shape; it lives as files on the hardware.

Hardware sets the limits. Software decides what actually happens.

Component focus

The processor: it follows instructions

The CPU carries out the instructions of a program: it calculates, compares, sorts and moves data.

  • Cores — more cores can handle more tasks at once.
  • Speed — measured in gigahertz, but only comparable within similar chips.
  • Cooling — a heatsink and fan prevent overheating.
The CPU does not think. It follows the instructions software gives it.
Workplace effect A weak CPU makes every program feel slow, especially spreadsheets, video and design software. Do not compare by GHz alone — generation, cores and the rest of the system matter.

Storage

Where files live

SSDFast, silent, no moving parts. The best choice for a work computer.
Hard drive (HDD)Larger and cheaper, but slower and sensitive to movement.
USB flash driveSmall portable storage for moving files between machines.
Memory cardUsed in cameras, phones and tablets for photos and files.
External driveA large backup drive connected by USB.
Cloud storageFiles held on a provider’s servers and reached over the internet.
The cloud is convenient, but it is someone else’s computer. Keep a local copy of critical work.

The operating system

What the OS does all day

  • Starts up — checks the hardware and loads the system.
  • Manages hardware — talks to devices through drivers.
  • Manages memory and processing — shares resources between programs.
  • Manages files and storage — folders, copying, moving and deleting.
  • Provides the interface — desktop, Start menu, taskbar and windows.
  • Manages users and security — sign-in, permissions and updates.
No operating system means no desktop, no apps and no files you can open.

Care and safety

Protect the machine and the data

  • Use a surge protector and shut down properly.
  • Keep vents clear and remove dust; never block airflow.
  • Keep liquids away and never force a connector.
  • Back up important files and test that the backup opens.
  • Update software and use strong passwords; lock the screen.
  • Set up the desk for comfort: screen at eye level, flat keyboard, supported back.
An SSD often makes an older computer feel new. More RAM helps with many open programs. Neither fixes slow internet or malware.
