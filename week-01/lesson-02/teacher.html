Teacher guide — Lesson 2

Everything needed to run the 150-minute session: preparation, a timed plan, answer keys, common misconceptions and differentiation notes.

150 minutes Beginner 30% theory · 70% practical Quiz + 30-mark assignment Classroom upload kit
Preparation

Before the class starts

  • Open the lesson site on the projector and test the slides, quiz and practice activities.
  • Bring at least one computer you can show — ideally a desktop and a laptop — plus a USB flash drive, an HDMI cable and a wired network cable.
  • If you will open a case, do it safely beforehand and check for sharp edges. Otherwise use clear labelled photos or a video.
  • Print the assignment brief and worksheet for learners without devices, or show them where to print.
  • Write one sample specification on the board (for example “Core i5 · 16 GB RAM · 512 GB SSD · Windows 11”) so learners can read it line by line.
  • Check that learners can open Settings → System → About and This PC on the machines they will audit.

Answer keys

Quiz and practice answers

Quiz — 10 questions

  1. B — hardware is the physical equipment you can touch.
  2. C — Windows 11 is software; the others are hardware.
  3. B — the CPU carries out instructions and calculations.
  4. B — RAM is temporary; storage keeps files when the power is off.
  5. C — save to storage such as an SSD or hard drive.
  6. A — a scanner sends data into the computer.
  7. A — HDMI commonly connects a monitor or projector.
  8. B — the OS manages hardware, files and programs.
  9. C — Excel is application software.
  10. B — video editing needs a strong GPU and plenty of RAM.

Practice lab

  1. Hardware or software: monitor H, Word S, keyboard H, Windows 11 S, printer H, antivirus S, flash drive H, Chrome S. (H = hardware, S = software.)
  2. Which part: instructions → CPU; temporary programs → RAM; keeps files → storage; images and video → GPU; converts mains power → PSU; manages hardware and files → operating system.
  3. Input, output or both: keyboard In, monitor Out, touchscreen Both, printer Out, microphone In, headset with mic Both, scanner In, speaker Out.

Assignment — model specifications

Accept other choices when the learner gives sound reasons. The reasoning matters more than the exact model. Check that RAM and storage are not confused.

  1. Accounts clerk → desktop with a Core i5/i7, 16 GB RAM, 512 GB SSD, a 24-inch screen plus a second monitor, Windows 11 Pro, Excel and accounting software, and a surge protector or UPS. Large spreadsheets and two screens need memory and screen space; a fixed desk does not need portability.
  2. Graphic designer → workstation with a Core i7/Ryzen 7, 32 GB RAM, 1 TB SSD, a dedicated graphics card, a 27-inch colour-accurate screen, Windows 11 Pro, design and video software, and an external backup drive. Large files and video need GPU power, memory and fast storage; colour accuracy matters for client work.
  3. Receptionist → desktop with a Core i5, 8–16 GB RAM, 256–512 GB SSD, a 21.5–24-inch screen, Windows 11, Word and email/browser, a printer and a surge protector. The work is office-based, so reliability, a comfortable keyboard and a clear screen matter more than portability.
Watch for these

Common misconceptions

“RAM and storage are the same.”RAM is temporary working memory; storage keeps files when the power is off. A 16 GB RAM / 512 GB SSD specification contains two different numbers for two different jobs.
“More RAM always makes a computer faster.”RAM helps when many programs or large files are open. It will not fix slow internet, a failing drive, malware or an old processor.
“The CPU is the whole computer.”The processor is one component. It needs memory, storage, a motherboard, power and cooling — and software to give it instructions.
“A higher GHz number is always faster.”Clock speed is only comparable within similar processors. Generation, cores, cache and the rest of the system matter.
“The cloud means there is no hardware.”Cloud storage runs on someone else’s servers. It needs internet access, and a local copy is still wise for critical work.
“The most powerful computer is the best choice.”Fit matters. A receptionist does not need a video-editing workstation, and a designer cannot work on a basic office desktop.
Support every learner

Differentiation and assessment

Learners without a device

Pair them with a device user for the practice lab. Print the reading and assignment brief. The system audit can be completed from photos or from a shared machine, and the specification sheet may be handwritten and still earns full marks for content and structure.

Advanced learners

Ask them to compare two specifications for the same role, or to calculate the cost of an SSD and RAM upgrade against buying a new machine. Challenge them to find five ports in the room and name a device for each.

Language support

Pre-teach six terms: hardware, software, processor, RAM, storage, operating system. Use the glossary and ask learners to give one local example for each. Allow answers in a familiar language first, then translate the key term.

Assessment link

The quiz is formative. The 30-mark specification sheet feeds the Computer Fundamentals component (10% of the programme). Day 5 adds the practical folder-and-document assessment for Week 1.

Homework: finish the reading, practice and quiz; complete and submit the specification sheet before Day 3.
