Week 1 · Day 3 · Core skills

Starting up, Windows 10/11 & the desktop

Switch on, sign in and find your way around Windows with confidence. Learn the desktop, Start menu, taskbar and window controls, then set up a comfortable, safe workstation for a full day of work.

2½ hours Windows 10/11 Practice + quiz Beginner

Quiz + assignment10 + 30 marks
Learning objectives

By the end of this lesson, you can…

  • Start up, sign in, lock, sign out, restart and shut down a Windows computer correctly.
  • Tell Windows 10 and Windows 11 apart and describe the main parts of the desktop.
  • Find apps, settings and files quickly with the Start menu and Search.
  • Open, move, resize, snap, switch and close windows without losing work.
  • Adjust the display, sound and desktop for comfortable, safe everyday work.

A computer is only as useful as your ability to find things on it. Learn the map once — the desktop, Start, Search, the taskbar — and every task after this becomes faster.
