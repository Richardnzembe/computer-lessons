Teacher guide — Lesson 3

Everything needed to run the 150-minute session: preparation, a timed plan, answer keys, common misconceptions and differentiation notes.

150 minutes Beginner 20% theory · 80% hands-on Quiz + 30-mark assignment Classroom upload kit
Preparation

Before the class starts

  • Test the lesson site on the projector: slides, practice, quiz and the assignment page.
  • Arrange working Windows 10 or Windows 11 machines — at least one per pair. This lesson is almost entirely hands-on.
  • Create or confirm a safe practice account on each machine. Never let learners use another person’s real account.
  • Plan a demonstration pair of apps for the window and Snap exercises — for example Word and File Explorer, or two browser windows.
  • Print the practice worksheet, quiz paper and assignment brief for learners without devices.
  • Check that learners can lock and unlock without losing work, and that they know their own sign-in details.

Answer keys

Quiz and practice answers

Quiz — 10 questions

  1. A — Start → Power → Shut down closes programs safely.
  2. B — Windows key + L locks the screen.
  3. C — signing out ends your session; locking keeps it open.
  4. B — the Start menu holds apps, settings and power options.
  5. D — the Search box is the fastest way to find an app by name.
  6. B — the notification area shows clock, network and volume.
  7. C — Maximise fills the screen.
  8. D — Windows key + left arrow snaps to the left half.
  9. C — Snap layouts arrange windows in Windows 11.
  10. D — close the program with the X, then use Task Manager if needed.

Practice lab

  1. What should you do: start of shift → Sign in; ten-minute meeting → Lock; end of day, power off at wall → Shut down; colleague needs the computer → Sign out; lunch, save power → Sleep; computer frozen → Restart.
  2. Name that part: Windows logo button → Start button; type an app, file or setting → Search; long bar with open apps → Taskbar; clock, network, volume → Notification area; small pictures on the main screen → Desktop icons; deleted files wait here → Recycle Bin.
  3. Which button or shortcut: fill the screen → Maximise; hide without closing → Minimise; return to previous size → Restore down; end the program → Close; side by side → Snap left / right; switch without the mouse → Alt + Tab; see all windows → Task View; reach the desktop → Show desktop.

Assignment — model answers

Accept other safe choices when the reasoning is sound. The key checks are: no cutting power, no shared accounts, and a clear difference between lock, sign out and shut down.

  1. Navigation check: award marks for recorded steps, not only ticks. Expected keys: Start button or Windows key; Search box; Windows key + ← / →; Alt + Tab; minimise button; Windows key + L.
  2. Desktop map: Start button (bottom-left on Windows 10, centre on Windows 11); Search (next to Start); Taskbar (bottom bar); Notification area (right of taskbar); Desktop icons (on the wallpaper); Recycle Bin (desktop icon); Title bar (top of a window); Show desktop (thin strip at the far right of the taskbar).
  3. Everyday actions: start of shift → sign in; cannot find a program → Search; read while typing → snap side by side; leave for ten minutes → lock (Windows key + L); colleague needs it → sign out; program frozen → close with X or Task Manager (Ctrl + Shift + Esc); bright screen → Settings → System → Display, or the brightness key; finished for the day → Start → Power → Shut down.
  4. Guide: look for numbered steps, a labelled sketch, at least one alternative method, the lock / sign out / shut down difference, and a safety tip such as 20-20-20. Clear beginner language earns full marks.
Watch for these

Common misconceptions

“Closing the lid shuts the computer down.”On most laptops the lid triggers sleep. The computer is still using power and unsaved work is still at risk. Shut down properly from Start → Power.
“Holding the power button is a normal way to switch off.”A forced power-off can lose unsaved work and damage files. Use Start → Power → Shut down; save the forced method for a completely frozen machine.
“Lock and sign out are the same.”Lock keeps your session and programs running behind the sign-in screen. Sign out ends your session and closes your programs so the next person can use their own account.
“Windows 10 and Windows 11 are completely different.”They run the same programs and share the same core ideas. Windows 11 centres the Start button and adds Snap layouts, Widgets and Quick Settings. Skills transfer.
“Minimise closes the program.”Minimise hides the window in the taskbar; the program keeps running. Close (X) ends the program and may ask you to save.
“A frozen program means the computer is broken.”Wait a moment, then close the program with the X. If it will not close, end the task in Task Manager. Restart only if the whole computer is stuck.
Support every learner

Differentiation and assessment

Learners without a device

Pair them with a device user and let them direct the actions while the partner drives, then swap. Print the reading, worksheet and assignment brief. The desktop map and everyday actions can be completed on paper from the printed diagrams and still earn full marks.

Advanced learners

Ask them to create a second virtual desktop and move a window to it, or to set up a Snap layout for three windows. Challenge them to find every method of reaching the desktop and time each one.

Language support

Pre-teach six terms: boot, sign in, lock, taskbar, window, shortcut. Point to each part on a real screen while saying the word. Allow learners to write the guide in a familiar language first, then translate the headings.

Assessment link

The quiz is formative. The 30-mark navigation guide feeds the Computer Fundamentals component (10% of the programme). Day 5 adds the practical folder-and-document assessment for Week 1.

Homework: finish the reading, practice and quiz; complete and submit the navigation guide before Day 4.
