Mouse, keyboard, typing & shortcuts

Build confident control of a computer. Learn mouse actions, useful keys, comfortable typing habits and shortcuts for everyday work.

Reading progress

Lesson 3 helped you find your way around the Windows desktop. Now practise the two tools you use most: the mouse and keyboard. Careful control helps you work more comfortably and avoid mistakes.

Section 01Mouse actions: point, click and move

A mouse moves an on-screen pointer. Rest your hand lightly and move the mouse on a flat surface. Small, controlled movements help you select accurately.

Use the right action

Click selects. Double-click usually opens a desktop item. Right-click opens a menu of useful actions. Drag and drop moves an item while you hold the button. Scroll moves through a page or list.

On many laptop touchpads, one finger moves the pointer, a tap clicks, two fingers scroll and a two-finger tap opens the right-click menu. Gestures can vary between models.

ActionWhat you doWorkplace example
ClickPress and release onceSelect a file or button
Double-clickClick twice quicklyOpen a desktop shortcut
Right-clickPress the right button onceSee actions for a file
DragHold, move, then releaseMove a window or file
ScrollRoll the wheel or gestureRead a long document

Section 02Pointer shapes

The pointer changes shape to show what you can do. The arrow selects items. A hand usually points to a link. An I-beam marks where text can be entered. A spinning circle means the computer is busy; wait briefly instead of clicking repeatedly. A two-headed arrow at a window edge lets you resize it.

Section 03Keyboard keys that do more

The keyboard has groups for entering text, editing and moving through a page. Learn the keys you use most often first.

KeyPurposeRemember
SpacebarAdds a spaceUse one space between words
EnterStarts a new line or confirms a choiceUse it for a new paragraph
BackspaceRemoves the character before the cursorBackspace works backwards
DeleteRemoves after the cursor or a selectionCheck selection first
ShiftMakes one capital or upper symbolHold while tapping the key
Caps LockKeeps letters uppercaseCheck it is switched off
TabMoves to the next form fieldUseful when filling forms
Arrow keysMove cursor or selectionUse for small adjustments

Ctrl and Alt are modifier keys: hold one while tapping another key to use a shortcut. The home row on a standard keyboard is A-S-D-F and J-K-L-;.

Section 04Typing accurately and comfortably

Typing is not a race. Accurate words and figures save time later, especially in names, dates and financial records.

  1. Sit with feet supported, shoulders relaxed and elbows near your sides.
  2. Place the keyboard in front of you and keep your wrists straight.
  3. Use a light touch and begin at a pace that lets you stay accurate.
  4. Read the source text first, then type one phrase at a time.
  5. Proofread names, dates, amounts and punctuation before saving.

Comfort matters

Keep the screen at a comfortable distance and take brief eye breaks. Stop and adjust if your hands, wrists, neck or eyes become uncomfortable.

Practise in short, regular sessions. If you are learning to touch-type, keep your fingers near the home row and look at the screen more than the keys.

Section 05Shortcuts for everyday work

A shortcut performs an action with the keyboard. Hold the first key, tap the next one, then release. These common Windows and Office actions are useful across many programs.

ShortcutActionExample
Ctrl + CCopy selected contentCopy without removing it
Ctrl + XCut selected contentMove a selection elsewhere
Ctrl + VPaste contentInsert at the cursor
Ctrl + ZUndo the last actionReverse an accidental edit
Ctrl + ASelect all in the active areaSelect document text
Ctrl + SSave the current fileSave as you work
Ctrl + POpen print optionsPrint or save as PDF
Alt + TabSwitch between windowsMove to another app
Windows + LLock the computerSecure a shared workstation
Windows + DShow the desktopReach desktop shortcuts

Copy leaves the original in place. Cut can move selected content when it is pasted. Save before large changes, and check what a shortcut did.

Section 06Practise safely

  • Keep drinks away from the keyboard and use a light touch.
  • On a shared computer, use your own account and lock the screen before leaving.
  • Never type a password where others can see it.
  • Ask before changing accessibility or system settings.

Section 07Check your understanding

  1. Which mouse action opens a context menu?
  2. Which key removes the character before the cursor?
  3. How does Ctrl + C differ from Ctrl + X?
  4. Which shortcut saves the current file?
  5. Why proofread a name or amount after typing?

Section 08Summary

Click to select, double-click to open, right-click for options, drag to move and scroll to navigate. Use editing keys deliberately. Shortcuts make routine work faster; accuracy, comfort and checking remain essential.
