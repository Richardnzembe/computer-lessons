Mouse, keyboard, typing & shortcuts

A computer becomes useful when you can control it comfortably and accurately. This lesson builds confident mouse and keyboard habits, then uses simple shortcuts to make everyday work faster.

Learning goals: identify mouse actions and pointer shapes; use the keyboard?s main key groups; type accurately with a comfortable posture; use common Windows shortcuts safely.

1. The mouse and pointer

A mouse moves an on-screen pointer. Keep it on a clear, flat surface and move it gently. Rest your hand loosely; avoid gripping or pressing hard.

  • Point: move the pointer over an item.
  • Click: press and release the left button once to select a button, link or file.
  • Double-click: click twice quickly to open a desktop item. If it does not open, adjust the speed or use one deliberate double-click.
  • Right-click: open a context menu of actions for the selected item.
  • Drag and drop: hold the left button while moving an item, then release. Check the destination before releasing.
  • Scroll: roll the wheel to move through a page or list.

On a laptop, the touchpad uses one-finger movement, a tap or press to click, two-finger movement to scroll, and a two-finger tap for right-click on many devices. Settings may vary.

2. Pointer shapes give clues

The pointer changes to show what Windows is doing. The usual arrow is ready to select. A hand often means a link. A text I-beam marks where text can be inserted. A spinning circle means the computer is busy; wait briefly instead of clicking repeatedly. A two-headed arrow at a window edge means you can resize it.

3. Keyboard groups and useful keys

  • Letter and number keys enter text and figures.
  • Spacebar inserts a space; Enter starts a new line or confirms an action.
  • Backspace removes the character before the cursor; Delete removes the character after it or a selected item. Check before deleting.
  • Shift makes one capital letter or the upper symbol on a key. Caps Lock keeps letters uppercase until switched off.
  • Arrow keys move the cursor or selection. Home and End move to the start or end of a line.
  • Tab moves between fields; Esc cancels or closes some menus.
  • Ctrl and Alt are modifier keys used with other keys in shortcuts. Hold the modifier first, tap the second key, then release.
  • Function keys (F1?F12) have app-specific jobs; laptop Fn keys may change their action.

4. Typing with accuracy

Good typing is relaxed and consistent. Sit with feet supported, shoulders relaxed, elbows near your sides and wrists straight. Place the keyboard directly in front of you. Keep the screen at a comfortable distance and take short eye breaks.

  1. Look at the text you need to enter and understand it first.
  2. Use a light touch; accuracy matters more than speed.
  3. Keep fingers near the home row (A?S?D?F and J?K?L?; on a standard QWERTY keyboard).
  4. Use the correct keys for capitals, punctuation, spaces and new paragraphs.
  5. Pause at the end to proofread names, dates, amounts and spelling.

Practise for short, regular periods. Track both accuracy and speed, but do not sacrifice accuracy to chase a typing score. On a shared computer, never type a password where others can see it.

5. Shortcuts that help at work

ShortcutTypical action
Ctrl + CCopy selected text or item
Ctrl + XCut selected text or item
Ctrl + VPaste copied or cut content
Ctrl + ZUndo the last action
Ctrl + ASelect all in the active field or document
Ctrl + SSave the current file
Ctrl + POpen print options in many apps
Alt + TabSwitch between open windows
Windows + LLock the computer
Windows + DShow or return to the desktop
Ctrl + Shift + EscOpen Task Manager

Shortcuts can vary by application. Save before major changes. Copy leaves the original in place; cut moves it when pasted. If a shortcut behaves unexpectedly, use the app menu and check the result.

6. Practice safely and comfortably

On a shared device, keep food and liquids away from the keyboard, use only your own account and lock the screen when stepping away. Ask before changing accessibility or system settings. If typing causes discomfort, stop, adjust posture and tell the instructor.

Quick recap

Click selects; double-click opens; right-click shows options; drag moves; scroll navigates. Use a light touch, proofread important entries and practise shortcuts only after selecting the intended content.

Check your understanding

  2. Which key removes the character before the cursor?
  3. What is the difference between Ctrl + C and Ctrl + X?
  4. Which shortcut saves the current file?
  5. Why should accuracy come before typing speed?
