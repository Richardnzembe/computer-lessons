Teacher guide: Mouse, keyboard, typing & shortcuts

Plan the core class, observe practical skills and give focused feedback. Use the extension when learners need more guided practice.

150-minute coreOptional 30-minute extensionClass 09 · Beginner Download teacher guide PDF Classroom upload kit
Preparation

Set up for a hands-on class

Before learners arrive

  • Check a working mouse or touchpad and keyboard for each learner or pair.
  • Prepare a blank text document and a harmless practice file.
  • Open the slides, practice lab and quiz; test the projector.
  • Print the reading and worksheet for learners who need paper access.

Learning outcomes

  • Use click, double-click, right-click, drag and scroll appropriately.
  • Use key functions to enter and edit text accurately.
  • Apply common shortcuts to complete routine tasks.
  • Type and proofread a short workplace message with comfortable technique.

Materials

Computer per learner or pair, projector, mouse or touchpad, keyboard, blank document, safe practice file, reading and worksheet, quiz paper and assignment brief.

Formative assessment

Observe a skill, then give one useful prompt

Use this guide during practice. It is for coaching, not grading.

1 · Observe

Watch the learner perform the task without taking over. Note what they can do independently.

2 · Prompt

Ask a focused question or give one small hint. Let the learner decide the next action.

3 · Retry

Invite a second attempt and name the progress. Record any skill that needs another demonstration.

FocusEvidence of learningIf support is neededStatus
Mouse controlSelects without opening; uses right-click to view options; scrolls deliberately.Model one action, pause, then ask the learner to repeat and describe the result.I / P / R
Keyboard editingUses Backspace before the cursor and Delete after it or on a selection.Place the cursor visibly in a sample word and ask which character will be removed.I / P / R
ShortcutsSelects a useful shortcut and explains why it matches the task.Name the task first (save, copy or switch); let the learner choose the keys.I / P / R
Accuracy and comfortChecks names and figures; uses a relaxed position and light touch.Pause the task, adjust one thing, and proofread the message one line at a time.I / P / R

Status key: I = independent; P = completes after a prompt; R = revisit after another demonstration.

Useful teacher prompt: “What are you trying to do, and what on the screen tells you that action worked?” Ask this after the learner acts; avoid naming the key before they have a chance to recall it.

Assessment resources

Answer keys and marking guidance

Quiz · 10 marks

  1. B — Double-click usually opens a desktop icon.
  2. C — Right-click opens the context menu.
  3. A — Drag holds, moves and releases an item.
  4. B — Backspace removes before the cursor.
  5. B — Shift makes one uppercase letter.
  6. C — Ctrl + C copies selected content.
  7. B — Ctrl + S saves the active file.
  8. A — Alt + Tab switches open windows.
  9. B — Proofreading catches errors before they affect records.
  10. C — Relaxed posture and accuracy support reliable typing.

Practice lab · expected responses

  • Mouse: click; double-click; right-click; drag; scroll.
  • Keyboard: Backspace; Delete; Enter; Shift; Tab; arrow keys.
  • Shortcuts: Ctrl + C; Ctrl + X; Ctrl + V; Ctrl + Z; Ctrl + S; Ctrl + P; Alt + Tab; Windows + L.

Assignment · 30 marks

Mouse actions 5; keyboard keys 6; shortcuts and workplace uses 10; typing habits 6; presentation and accuracy 3. Accept equivalent wording when the function is correct.

Likely sticking points

Common misconceptions

?Click and double-click are the same.?A click usually selects; a double-click usually opens a desktop item.
?Backspace and Delete do the same thing.?Backspace removes before the cursor; Delete removes after it or removes a selection.
?Cut and copy both leave the original in place.?Copy leaves the original; cut prepares selected content to move when pasted.
?Fast typing is the only goal.?Accuracy, comfort and proofreading matter more than speed, especially for names and figures.
Access and follow-through

Support every learner

Limited device access

Pair learners and rotate operator/coach roles. Where no computer is available, learners can write the sequence and arrange a short demonstration with the instructor. Accept the written guide while access is arranged.

Additional support and extension

Provide printed reading, larger text, extra time or an alternate pointing device as appropriate. Confident learners can prepare a short note, copy and move a sentence, undo an edit, save, and teach a shortcut to a partner.
