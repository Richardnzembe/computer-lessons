Teacher guide: mouse, keyboard, typing & shortcuts

Week 1 · Lesson 4 · Class 09 · Beginner level

Learning outcomes

  • Demonstrate click, double-click, right-click, drag and scroll.
  • Use keyboard editing and navigation keys accurately.
  • Type and proofread a short workplace message comfortably.
  • Apply common shortcuts and explain their purpose.

Materials

One computer per learner or pair, mouse or touchpad, keyboard, projector, practice worksheet and sample message.

Preparation

Open a blank text document and a browser page. Prepare a harmless practice file for drag-and-drop, check that devices are available, and seat learners where screens are visible.

Evidence to look for

  • Mouse actions are deliberate and appropriate.
  • Learners can explain Backspace versus Delete.
  • Shortcut choices match the task.
  • Names and figures are checked before saving.
  • Posture is relaxed and devices are handled carefully.

Formative assessment

Listen for the reason behind an action, not only the key name. Invite each learner to demonstrate at least one mouse action and one shortcut.

Answer keys

Quiz, practice and assignment

Quiz · 10 questions

  1. B - Double-click usually opens a desktop icon.
  2. C - Right-click opens the context menu.
  3. A - Drag holds, moves and releases an item.
  4. B - Backspace removes before the cursor.
  5. B - Shift makes one uppercase letter.
  6. C - Ctrl + C copies selected content.
  7. B - Ctrl + S saves the active file.
  8. A - Alt + Tab switches open windows.
  9. B - Proofreading catches errors before they affect records.
  10. C - A relaxed posture and accuracy support reliable typing.

Practice lab

  1. Mouse: click; double-click; right-click; drag; scroll; click.
  2. Keyboard: Backspace; Delete; Enter; Shift; Tab; Arrow keys.
  3. Shortcuts: Ctrl + C; Ctrl + X; Ctrl + V; Ctrl + Z; Ctrl + S; Ctrl + P; Alt + Tab; Windows + L.

Assignment marking

Accept equivalent wording when the function is correct. Award mouse marks for correct actions, keyboard marks for accurate functions, and shortcut marks for the action and an appropriate use. A paper response is acceptable where a device is unavailable.

Common misconceptions

Correct gently with a demonstration

"Click and double-click are the same."A click usually selects; a double-click usually opens a desktop item.
"Backspace and Delete always remove the same character."Backspace removes before the cursor; Delete removes after it or removes a selection.
"Cut and copy both leave the original."Copy leaves the original; cut is intended to move selected content when pasted.
"Fast typing is the only goal."Accuracy, comfort and proofreading matter more than speed, especially for workplace names and figures.

Support and access

Pair learners and rotate the driver/coach roles. Provide the printed reading and worksheet where a device is unavailable. Demonstrate touchpad alternatives, allow extra time and use larger text or accessibility settings when helpful.

Extension

Ask confident learners to prepare a short office note using copy, paste and undo, then proofread and save it. Invite them to teach one shortcut to a partner and explain when it is useful.
