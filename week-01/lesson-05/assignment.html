Week 1 · Lesson 5 · Practical assignment

Work Documents: organise, save & retrieve

Complete the file and folder practical from the course brochure. Demonstrate an orderly structure and produce a one-page document that you can locate again.

30 marks60“90 minutesSubmit via Google Classroom
Scenario · Dalswin Business Centre

A new office assistant must prepare a simple document system so staff can save and retrieve routine work. You are asked to establish the folders, prepare a useful one-page document, and show that it can be found again.

Task requirements

  1. Create a parent folder named Work Documents.
  2. Inside it, create Reports, Letters and Presentations.
  3. Type a one-page workplace document. Include a suitable heading, date, purpose and organised content. A short office opening checklist or welcome letter is suitable.
  4. Save it in the most relevant subfolder using a clear filename (for example, Office_Opening_Checklist).
  5. Rename the file using a consistent, descriptive name if needed.
  6. Show how you locate it again in File Explorer. If possible, open it to confirm it is the correct document.
  7. Complete the written reflection on safe file handling.

Evidence to submit

  • A screenshot or instructor-checked demonstration of the folder structure.
  • The saved one-page document.
  • A short note stating its full folder path and explaining how you renamed and found it.
  • If no computer is available, complete the written folder tree, document draft and step-by-step procedure; arrange a practical check with the instructor.

Before submitting

  • My folder is named Work Documents.
  • Reports, Letters and Presentations are inside it.
  • My one-page document is in the most suitable subfolder and opens correctly.
  • The filename is clear and accurately recorded.
  • I can explain the folder path and how I located the file.
  • I used only practice files for any delete demonstration.
  • My evidence is readable and contains no private information.
Suggested submission name: Lesson5_FilesFolders_YourName. Do not upload private or confidential workplace records.
