Work Documents: organise, save and retrieve

Complete the Week 1 practical assessment from the course brochure. Build the folder structure, produce a one-page document, save it correctly and show that you can find it again.

30 marks · 60-90 minutes
Week 1 · Lesson 5 · Practical assessment

Dalswin Business Centre

Prepare a simple filing system and a useful workplace document.

30marks
SetWeek 1 · Lesson 5
DueEnd of lesson or by instructor
FormatFolder + document + evidence
SubmitGoogle Classroom or instructor
Your role: You are preparing a new office assistant's working area. Staff need one clear place for their documents and a short, readable office opening checklist. Build the folder structure below, create the document and prove you can locate it again. Use only the computer and practice location assigned by your instructor.

1Create the folder structure 8 marks

Create a parent folder named Work Documents. Inside it, create these subfolders:

Work Documents
  Reports
  Letters
  Presentations

Show the structure in File Explorer. A screenshot or instructor observation is acceptable.

2Prepare a one-page document 8 marks

Create an Office Opening Checklist with a clear title, date, purpose and at least five ordered steps. Use readable spacing and proofread all words. Do not include private information.

3Save and name the file 6 marks

Save it in the most suitable subfolder, for example Letters or Reports. Use a descriptive filename such as Office_Opening_Checklist_2026-11-21. Record the complete path here:

4Rename and retrieve 5 marks

Rename the practice file if needed. Close the document, locate it again with File Explorer or Search, confirm its location and reopen it.

5Safe handling and evidence 3 marks

Explain what you check before deleting a file. If you demonstrate deletion, use only a temporary practice file you created and have permission to remove.

Evidence to submit

  • Screenshot or instructor check of the folder structure.
  • Your one-page document.
  • The full folder path and a brief note explaining how you renamed and found it.
  • If no device is available, submit the written folder tree and document draft, then arrange a practical check.

Before submitting

  • My folder is named Work Documents and contains all three categories.
  • My document is in a suitable folder and opens correctly.
  • The filename is clear and I recorded the path.
  • I used only my temporary practice file for deletion.
  • My evidence is readable and contains no private information.
