Week 1 · Day 5 · Computer fundamentals

Files, folders & documents

Build an orderly workplace filing system. Create folders, save a one-page document to the right place, rename it clearly and find it again.

Learning outcomes

By the end of this lesson, you can...

  • ✓Explain the difference between a file, folder, subfolder and file path.
  • ✓Create Work Documents with Reports, Letters and Presentations inside it.
  • ✓Create and save a one-page workplace document to an appropriate folder.
  • ✓Rename a file, confirm its location and retrieve it using File Explorer.
  • ✓Handle copy, move and delete actions carefully and with permission.

A useful filing system helps another person predict where a document is and what it contains.

Class plan

150 minutes from concept to competent practice

The reading is a short preparation resource. The full lesson includes instructor demonstration, a substantial guided computer lab and assessment.

30 min

Theory & discussion

Files, folders, paths, naming conventions, Save versus Save As, and safe file handling.

30 min

Instructor demonstration

Model the complete workflow on a projected Windows 10/11 computer. Learners predict each next action.

60 min

Guided practical lab

Build the folder structure, draft and save a document, rename it, find it and practise a safe copy/move/delete scenario. Instructor checks each milestone.

20 min

Independent exercises

Complete the practice worksheet (10 min) and knowledge quiz (10 min).

10 min

Review & questions

Explain a file path, correct common errors and reflect on safe handling.

+30 min

Optional extension

Complete the full one-page workplace document, add a date/version convention and peer-check another learner's structure.

Time check: 30 + 30 + 60 + 20 + 10 = 150 minutes. Reading takes about 20 minutes before or at the start of the class; it does not replace the practical class time.
