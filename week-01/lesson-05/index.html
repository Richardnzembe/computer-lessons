Class 09 · Week 1 · Lesson 5

Files, folders & documents

Organise everyday computer work. Create a practical folder structure, prepare and save a one-page document, rename it clearly and find it again.

2Â½“3 hours150-minute corePractical + quiz10-question quiz · 30-mark task
Learning outcomes

By the end of this lesson, learners can…

  • Explain the difference between files, folders, subfolders and file locations.
  • Create Work Documents with Reports, Letters and Presentations subfolders.
  • Create a one-page document and save it to a chosen folder.
  • Rename, copy or move a practice file and confirm its new location.
  • Locate a saved item using File Explorer and search.
  • Delete a temporary practice file safely and explain the Recycle Bin.

150-minute core lesson

30 min · Concepts: File vs folder, folder trees, naming, save vs Save As, locations and retrieval.

30 min · Demonstration: Model the folder tree, create a document, Save As, rename and find it. Use a safe practice file for deletion.

60 min · Guided practical: Learners create folders and a short document with instructor checkpoints.

20 min · Independent practice: Complete the worksheet and self-check quiz.

10 min · Review: Learners explain their file path and one safe handling habit. Includes a short break within the session.

Optional +30 min: Complete the full one-page workplace document, practise search and peer-check the folder structure.
