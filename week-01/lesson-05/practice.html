Week 1 · Lesson 5 · Guided practice

Build, save & find

Work through the sequence in order. Use a practice computer, or write the steps and expected folder path if a device is unavailable. Do not use real workplace files for deletion practice.

30“45 minutes3 activitiesSave progress locally

01 · Plan the folder structure

Arrange these labels into the correct hierarchy: Reports · Work Documents · Letters · Presentations.

On a computer: In Documents, create Work Documents. Open it and create the three subfolders.

02 · Save and name a document

You have written an office opening checklist. Choose a suitable folder and a clear filename. Explain the steps for saving this as a new document.

03 · Rename, locate and handle safely

A colleague cannot find Document1. Write one improvement to its filename, then describe how you would rename it and verify the location. What kind of file should you use to practise deletion?

Completion check: You can show the folder tree, save a document to its intended location, rename it, and open it again from File Explorer.
