Files, folders & documents

A short guide to organising workplace information. Read this before the 150-minute class; the time plan includes demonstration, a 60-minute practical lab, exercises and review.

On this page

  2. Build the folder structure
  3. Name files clearly

  7. Workplace example

In an office, a document is useful only when it is accurate and can be found again. A simple folder structure and a clear filename help you store work reliably and let colleagues understand what they are opening.

Section 01File, folder and path

A file is a saved item containing information: a letter, photograph or spreadsheet. A folder groups files and other folders. A folder placed inside another folder is a subfolder. A path is the route from a starting location to the saved item.

TermMeaningExample
FileSaved contentMeeting_Notes.docx
FolderContainer for related itemsWork Documents
SubfolderFolder inside another folderLetters
PathSequence of locationsDocuments > Work Documents > Letters

A filename can include an extension such as .docx or .pdf. The extension helps Windows and applications identify the file type; changing it does not convert the file.

Section 02Build the folder structure

The Week 1 practical begins with one parent folder and three subfolders:

Folder map

Work Documents
  Reports
  Letters
  Presentations

  1. Open File Explorer using the taskbar or Windows + E.
  2. Choose Documents (or the location assigned by your instructor).
  3. Select New > Folder. Type Work Documents and press Enter.
  4. Open Work Documents. Create Reports, Letters and Presentations inside it.
  5. Check the tree: all three categories should be one level below Work Documents.

Menu wording can vary slightly on Windows 10 and 11. You may also right-click an empty area and choose New > Folder.

Section 03Name files clearly

A useful filename describes the content so you can recognise it later. For example, Office_Opening_Checklist_2026-11-21 is more informative than Document1 or final-final.

  • Use a short topic and purpose.
  • Add a date or version when it helps; use one consistent date order such as YYYY-MM-DD.
  • Choose spaces or underscores consistently.
  • Keep names easy to scan and avoid meaningless punctuation.
  • Leave the extension in place unless your instructor asks you to change the format.

Workplace habit

Agree on a naming pattern for shared work. A clear, dated name helps staff distinguish a current document from an older copy.

Section 04Create and save a document

Open the available word processor and prepare a one-page workplace document. Include a clear heading, date, purpose and organised information, such as an office opening checklist.

  1. Choose File > Save As for a new document.
  2. Browse to the intended folder, for example Documents > Work Documents > Letters.
  3. Enter a descriptive name and select the format required by the course.
  4. Select Save. Check the title bar or File menu to confirm the document is saved.
  5. Use Ctrl + S to save changes while you work.

Save As lets you choose a new name or destination (or create a separate copy). Save updates the current file. Check the destination before you confirm.

Section 05Rename, copy and move

ActionCommon methodCheck afterwards
RenameSelect the item; press F2 or use the context menu; type the new name and press Enter.The new name is clear; the extension remains.
CopyCtrl + C, open destination, Ctrl + V.The original is still present.
MoveCtrl + X, open destination, Ctrl + V.The item is in the new location.
SearchSearch a distinctive word in File Explorer.Check the folder path and open the correct result.

Before moving an important file, confirm the destination and whether the original should remain. After a rename or move, verify the result and open the document.

Section 06Find and delete safely

Use File Explorer breadcrumbs to see where you are. Browse the parent folder or search for a distinctive part of the filename. Confirm the result's location before opening, editing or sharing it.

Delete only files you own or have permission to remove. Practise with a temporary file, never an important record. Check the selected item and location before pressing Delete. Many items deleted from a local drive go to the Recycle Bin, but removable drives, network locations and settings may behave differently. Empty the Bin only when authorised and certain.

Pause before deletion

Check the selected filename, confirm you have permission, and make sure it is only a practice item. Ask the instructor if you are unsure.

Section 07Workplace example

A staff member drafts an office opening checklist. They save it inside Letters with a descriptive name, then reopen File Explorer and locate it. If asked to send a copy, they use Copy and verify both the original and the destination item. They never practise deletion on real work.

  1. State the full path from Documents to the checklist.
  2. Explain why Save As is used the first time.
  3. Describe how you would confirm a renamed file is still in the correct folder.
  4. Name one check to make before deleting a practice file.

Section 08Summary check

Use a small, logical folder structure; name files so their purpose is clear; save new work to a known location; and confirm a rename, copy or move. Delete only authorised practice items.

Ready for the class?

You should be able to explain the Work Documents folder map and the difference between Save and Save As. The instructor demonstration and practical lab will give you time to perform the steps.
