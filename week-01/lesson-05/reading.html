Week 1 · Lesson 5 · Reading

Files, folders & documents

Learn to build an orderly workplace folder system, create and save a document, rename it clearly, and locate it again with confidence.

20“25 minute readingBeginnerWindows 10 / 11
Learning outcomes. By the end, you can explain files and folders; create the Work Documents folder with three subfolders; create and save a one-page document; rename and locate files; and delete practice files safely.

1 · Files and folders: the basic idea

A file stores information, such as a letter, photograph or spreadsheet. A folder groups related files and other folders. Think of a folder as a labelled container: the label should help another person predict what belongs inside.

TermMeaningExample
FileA saved item with contentMeeting_Agenda.docx
FolderA container used to organise itemsWork Documents
SubfolderA folder inside another folderLetters inside Work Documents
File nameThe identifying name of an itemClient_Welcome_Letter
Location / pathThe route of folders that leads to an itemDocuments > Work Documents > Letters

2 · Build a simple, useful folder structure

Start with a broad folder, then make categories that match the work. For this course, create:

Work Documents
- Reports
- Letters
└── Presentations

In Windows, open File Explorer from the taskbar or press Windows + E. Choose a suitable place such as Documents. Select New > Folder (or right-click an empty area and choose New > Folder), type Work Documents, and press Enter. Open it and repeat for Reports, Letters and Presentations. Menu wording may vary slightly by Windows version.

Good organisation: Use folders that reflect how you will retrieve the work. Avoid vague names such as “Stuff”, duplicate structures, and unnecessary nesting.

3 · Give files clear names

A good file name identifies its topic and, when helpful, date or version. Use a consistent pattern, for example Staff_Meeting_Summary_2026-11-21. Keep names concise, meaningful and easy to scan.

  • Use words that describe the content and purpose.
  • Use dates in a consistent order such as YYYY-MM-DD.
  • Use spaces or underscores consistently; avoid strings of punctuation.
  • Avoid names like “new”, “final-final” or “Document1”. Add a version or date instead.
  • Do not remove the file extension (such as .docx); Windows may hide extensions by default.

4 · Create and save a document

  1. Open the word-processing program available to you.
  2. Type a short one-page workplace document. Include a clear heading, date, short purpose statement and a few organised points.
  3. Choose File > Save As for a new document. Browse to Documents > Work Documents > Letters (or the folder your instructor assigns).
  4. Enter a descriptive name, such as Office_Opening_Checklist, and choose the format required by your program.
  5. Select Save. Check the title bar or File menu to confirm the document is saved.
  6. Continue editing and use Ctrl + S regularly to save changes.

Save updates the current file. Save As creates a named copy or saves to a different location. Check the location before saving; two files with the same name in different folders are still separate files.

5 · Rename, move and copy with care

ActionTypical methodCheck
RenameSelect the item, press F2, type the new name, press Enter; or use the context menuChange the name, not the extension
CopyCopy then paste into the destination (Ctrl+C, Ctrl+V)The original remains where it was
MoveCut then paste (Ctrl+X, Ctrl+V), or drag carefullyConfirm the destination before moving
LocateBrowse through folders or search by a distinctive nameCheck the folder path and modified date

After a move or rename, verify the item is in the expected place and opens correctly. When working with important records, follow your organisation’s storage and naming rules.

6 · Delete practice items safely

Delete only files you own or have permission to remove. Practise with a temporary file, not real work. In File Explorer, select the practice item and press Delete, then confirm if prompted. Many locally deleted items go to the Recycle Bin, where they can be restored; removable drives, network locations and some settings may behave differently.

Safe habit: Pause and check the selected item and location before deleting. Empty the Recycle Bin only when you are certain its contents are no longer needed and you have permission.

7 · Find your work again

Use File Explorer’s address bar and breadcrumb trail to see where you are. Open the parent folder and scan the categories. Search for a distinctive word from the file name if needed, then confirm the result’s location before opening or sharing it. Save files in a known course or work folder rather than leaving them scattered on the desktop or in Downloads.

8 · Check your understanding

  1. How is a file different from a folder?
  2. Where should the Letters folder sit in today’s structure?
  3. Which command should you use to save a new document in a chosen folder?
  4. What does Ctrl + S do after the first save?
  5. What should you verify after renaming or moving a file?
  6. Why should deletion practice use a temporary file?

Summary

A small, logical folder structure makes work easier to store and retrieve. Name files clearly, save new documents to the intended location, save changes regularly, and verify each rename or move. Delete only items you are authorised to remove.

Before you move on: Practise building Work Documents with Reports, Letters and Presentations. Then create a one-page document, save it in the correct folder, rename it and locate it again.

Quick practice ? explain the retrieval path

Scenario: You saved Office_Opening_Checklist inside Letters. Tell a partner the path from Documents to the file. Then explain how you would check that a search result is the correct copy.
  1. Open File Explorer and begin at Documents.
  2. Open Work Documents, then Letters.
  3. Find the named document and check its name and location.
  4. Open it to confirm the contents are correct.
  5. If two copies appear, compare locations and modified dates before choosing.

Reflect: Which part of the filename helps you recognise the document? What should you do before moving or deleting a shared item?
