Instructor resource · Week 1 · Lesson 5

Teacher guide: Files, folders & documents

Prepare a practical session that follows the Week 1 brochure outcome. Learners create Work Documents with three subfolders, type a one-page document, then save, rename and locate their work.

150-minute coreOptional 30-minute extensionClass 09 · Beginner
Download teacher guide PDFClassroom upload hub
Preparation

Set up the practical safely

Before class

  • Check File Explorer and a word processor on each learner device or pair station.
  • Prepare an assigned practice location and one disposable file for the deletion demonstration.
  • Have the reading, worksheet, quiz and assignment brief ready in print or Classroom.
  • Project the screen and model each action before learners perform it.
  • Remind the class to use practice files only and follow local storage rules.

Success criteria

  • Work Documents is the parent folder.
  • Reports, Letters and Presentations are one level below it.
  • A one-page document is saved to a suitable folder with a meaningful name.
  • The learner can state the path, rename the file and retrieve it.
  • Delete, copy and move actions are deliberate and verified.
Run sheet

Teaching notes

Common errors and responsive support

Misconceptions

  • Save equals Save As: model choosing the destination for a new file, then updating it with Save.
  • Copy equals move: compare whether the source remains.
  • Extension is part of the topic name: preserve .docx or other extension; renaming does not convert format.
  • Recycle Bin catches every deletion: behaviour differs for network and removable locations.
  • Desktop is a filing system: practise saving into a known course folder.

Adaptation

More support: provide a printed folder tree, demonstrate one action at a time, pair learners by roles and allow written planning where device access is limited.

Extension: make a dated copy, compare paths and modified dates, use Search and explain how you identify the current file.

Assessment key

Quiz answers & marking notes

Quiz: 1 A · 2 C · 3 A · 4 A · 5 A · 6 C · 7 A · 8 A · 9 A · 10 A. Award one mark for each correct answer. Target: 8/10.

Assignment: award up to 30 marks using the rubric in the learner brief. Credit correct equivalent filenames and suitable choices of subfolder; require a path and successful retrieval for full marks.
