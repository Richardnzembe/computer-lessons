Instructor resource · Week 1 · Lesson 5

Teacher guide

Facilitate the course’s practical file-management objective with a modelled folder structure, coached document saving and observable retrieval skills.

150-minute coreOptional 30-minute extensionClass 09 · Beginner

Preparation

  • Provide a Windows 10/11 device per learner or pair where possible.
  • Prepare a safe practice area in Documents and a disposable file for deletion practice.
  • Confirm learners can open a word processor and File Explorer.
  • Print the reading, worksheet and assessment brief as needed.

Success criteria

  • Correct parent and three subfolders.
  • Document saved in an intended location with a useful name.
  • Learner can describe the path and find the item.
  • Deletion is restricted to authorised practice items.

Materials

Computer, projector, File Explorer, word processor, safe sample file, worksheet, quiz and assignment brief.

Formative observation

Look forPromptEvidence of understanding
Hierarchy“Which folder contains Letters?”Learner identifies Work Documents as parent.
Saving“How will you choose the destination for this new file?”Uses Save As and selects the intended path.
Naming“Could a colleague recognise this file later?”Chooses concise, descriptive name and preserves extension.
Retrieval“Show how you would find it again.”Browses/searches and confirms location.
Safety“What should you check before deleting?”Checks selection, permission and uses disposable practice file.

Quiz answer key

1 A · 2 C · 3 A · 4 A · 5 A · 6 C · 7 A · 8 A · 9 A · 10 A. Accept equivalent explanations where the practical sequence and safety reasoning are correct.

Common misconceptions

  • “Save” and “Save As” are identical: clarify that Save As chooses a name/location or creates another copy; Save updates current file.
  • Moving is copying: ask learners to confirm whether the source should remain.
  • Changing an extension renames the document: explain that extensions identify format and should not be edited casually.
  • Recycle Bin always stores deleted files: clarify location/device/settings can affect deletion behavior.
  • Desktop is the best storage location: reinforce a known, logical course/work folder.

Differentiation

More support: provide a printed tree, demonstrate one action at a time, pair learners by task role, and allow a written procedure where equipment is unavailable. Extension: add a date-based filename, make and identify a copy, use search, and explain which copy is current. Adapt to installed software and local file policies.
